# Rust 学习教程

这是一本从示例代码出发的 Rust 学习笔记，也是一份配套 `src/study` 示例模块的教程索引。

这本书按照“先能写，再理解为什么，再进入工程化和并发异步”的顺序组织内容，适合已经有一点编程经验、但刚开始系统学习 Rust 的读者。

## 1. 封面

- 主题：Rust 基础、内存管理、类型系统、并发与 async 编程
- 代码：每个主题在 `src/study` 中都有对应示例模块
- 阅读方式：先读文档，再运行对应 `demo`，最后自己修改示例验证理解

## 2. 学习路线

1. 先掌握基础语法、Cargo 构建系统和泛型。
2. 再重点理解 Rust 最核心的内存管理：所有权、借用、智能指针、内部可变性和生命周期。
3. 之后学习错误处理、结构体、trait、模块、闭包和 Rust 的面向对象写法。
4. 最后进入宏、并发、文件/网络 IO 和 async 编程。

## 3. 如何阅读

建议按左侧目录顺序阅读。Rust 的知识点彼此关联很强，尤其是所有权、生命周期、trait 和 async，如果中途觉得绕，可以先记住结论，再回到代码示例里反复运行和修改。

本教程配套代码在 `src/study` 目录中，每个示例模块都只对外暴露一个 `demo` 函数，方便在 `main.rs` 中按章节单独调用。
